## Шаг 2 · Прогон виджетов — один шаг, подшаги

На каждом подшаге:

1. Агент пишет сценарий (если его ещё нет) и гоняет `npm run test:a11y` по этому виджету.
2. Ошибок нет — сохраняет снимок рядом со сценарием, коммит, следующий виджет.
3. Нашли косяк в виджете — стоп. Промпт оркестратору на правку. Цикл: оркестратор → ревью лидом → коммит. Потом тот же виджет прогоняем снова, снимок, коммит сценария, дальше.
4. Listbox и Combobox сюда не входят.

Куски, не виджеты, пропускаем: ячейка таблицы, подпись поля, ряд иконок, чистая панель.
