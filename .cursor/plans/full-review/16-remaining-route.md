## Шаг 4 · Пустая строка и дефолты текста (после шага 3)

Модель зафиксирована. Пустая строка в стейте = пропа нет (ключ в JSX не пишем). `placeholder=""` не моделируем. Компоненты `''` в «не передали» сами не переводят.

### Коробочная строка в компоненте

SearchField (`Search…`), Listbox (`Select…`, `Nothing found`), RangeInput (`Select range`, `From`, `To`, тексты валидации). Стартовый стейт витрины **импортирует** константу. LocalePicker своей копии `Select…` не заводит. Listbox дефолт поиска не заводит — `searchPlaceholder` пробрасывает в SearchField.

Без пропа на экране снова дефолт: подсказку нельзя выключить, только переопределить. `Set` пишет константу в стейт.

### Input

Константы в компоненте **нет**. Витринный `e.g. value` — только первый стейт, литерал. `Set` открывает пустое поле; без пропа подсказки нет.

### Уже сделано в шаге 3

Импорт констант Listbox / SearchField / RangeInput в стартовый стейт. Литерал `Range: any` снят.

### Код этого прогона

Мост превью: пустое после trim → ключа нет, не `=""`. Скаляры SearchField / Listbox / LocalePicker / RangeInput (`placeholder`, `fromPlaceholder`, `toPlaceholder`, `searchPlaceholder`, `emptyMessage` у Listbox — только при `showSearch`) и Input (`placeholder`, `label`, `error`) — уже так; не ломать.

Добить, если ещё уходит `''`:
- `validationMessages` RangeInput: в объект только непустые ключи; все пустые — пропа нет. Merge в компоненте иначе оставляет `''` вместо коробочного текста.
- `errorPlaceholder` Input и RangeInput: пустое → ключа нет (коробочной строки нет, как у подписи).

`text-group`: поле `contents[].boxedString` — Set пишет константу. Имя не менять. Поля без константы (Input placeholder, Label) — без `boxedString`. Схлопывание не ломать.

**Пропуск.** Не монтировать узел пустого результата Listbox, если строки нет. Высота `Nothing found` не этот шаг. Закрытие шага в этом файле — после коммита, не в этом прогоне.

По закрытии — дописать сюда «закрыто» и дату/коммит.
