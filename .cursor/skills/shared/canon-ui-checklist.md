### Архитектура стилей (§8.2–§8.4)

1. Классы пропсов и место дефолта — §8.2: вид дефолтится в генераторе, проброс — в `index.tsx`; дубль дефолта вниз по дереву запрещён.
2. Координация родитель → ребёнок — §8.3: статика — проп в JSX; динамический highlight — наследование CSS или канал переменной.
3. Лестница владения — §8.4: пропсы роли → layout-пропсы слота → канал состояний → геттеры для натива. Адресация ребёнка селектором для вида/состояний — нарушение; обёртка без функции — нарушение.

## Distill (аудит starter; дополняет канон)

- **flex-комментарий** — каждый `display: flex` в `*.styles.ts` несёт обоснование «почему не grid» (исключения — уже в `project.mdc`). Голый flex без обоснования = нарушение (добавить комментарий; раскладку не менять).
- **anchored-portal dedup** — новый anchored-слой (portal + dismiss + focus-trap + позиционирование) только через `@ui/anchored-portal`, не локальная копия `createPortal` / dismiss / focus-trap. ARIA (`role`, `aria-modal`, `aria-haspopup`) остаётся на виджете.
- **deep-import `../` между ui-примитивами** — в `src/ui/**` чужой примитив только через barrel `@ui/<name>`. Исключение: свой подпримитив (`./…`) и доменный модуль того же пакета. Grep `from '\.\./'` в `src/ui/**`.
- **table spacer** — невидимый spacer (`aria-hidden`, фикс. размер под отсутствующий сосед) допустим только с комментарием-инвариантом «зачем и что сломается при удалении». Иначе — замечание / правка.
- **semantic / landmarks** — один `<main>` на view задаёт **страница** (`pages/*`), не router и не корень `@ui/sidebar`. Card/блок с самостоятельным заголовком — `as="article"` / `as="section"` на call site (дефолт `div` — техн./popover-shell). Центральная модалка — `<dialog>` (`@ui/modal`), не portal-div.
- **Витрина / DS-canon** — публичный `@ui/<name>` имеет секцию в `pages/showcase` (settings + widget). Demo-only упрощение помечено «Не переносить в продуктовый код»; при смеси с copyable — маркер указывает копируемую часть. Runtime-поток примитива показан, если он есть (напр. Toast через provider + hook). Имя настройки витрины не совпадает с kit-осью при разном действии. Нет модуля-сироты в витрине.
- **Table nested head** — голова группы верхнего уровня → group-cell; вложенная сворачиваемая → nested-cell + expander (тот же `nestDepth`); витрина показывает nested collapsible, если kit это поддерживает.
- **Infra (при касании конфигов)** — stylelint покрывает `*.styles.ts`; eslint: barrel/`no-restricted-imports`, `import-x/no-duplicates`, `jsx-a11y`. Порядок CSS-свойств — зона stylelint, не ручной чеклист.

## Витрина (`pages/showcase`, showcase.mdc)

- Порядок полей настроек: `size → shape → tone → value` (пропуск отсутствующих осей).
- Ключ `*WidgetState` совпадает с именем пропа примитива.
- Лейбл контрола — человеческая метка (`Size:`), не сырое имя пропа (`sizePreset`).
- Превью и runtime-путь передают один набор осей.
